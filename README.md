# Paras Vinubhai Maniya — Academic Website

A responsive, single-page academic profile built with HTML and CSS for GitHub Pages.

## Publish on GitHub Pages

1. Sign in to GitHub and create a **public** repository named `YOUR-GITHUB-USERNAME.github.io`.
2. Upload `index.html` from this folder to the repository root.
3. (Optional) Upload your profile picture as `profile.jpg` and update the portrait section in `index.html` to use it.
4. In the repository, open **Settings → Pages**.
5. Under **Build and deployment**, select **Deploy from a branch**, choose `main` and `/ (root)`, then save.
6. After publishing, your website will be at `https://YOUR-GITHUB-USERNAME.github.io`.

## Before publishing

- Replace the generic Google Scholar, ORCID, and LinkedIn links with your personal profile URLs.
- Replace the thesis link with the exact handle URL.
- Add your publications and, if desired, your CV PDF.
- If you use a public repository, remember that all files committed to it are publicly visible.
